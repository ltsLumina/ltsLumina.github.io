## What

<quote>
<p>The Gameplay Ability System (GAS) plugin <a href="https://dev.epicgames.com/documentation/unreal-engine/gameplay-ability-system-for-unreal-engine">"is a framework for building attributes, abilities, and interactions that an Actor can own and trigger."</a></p>
</quote>

Many of my projects use it for stats, movement, hero abilities, interactions, and more.  
The system itself is very extensive – with a steep learning curve – but once mastered, it is incredibly powerful, and a reason why I have decided to use it so extensively.  
Furthermore, it is frequently used in the game industry, so learning it for that purpose served another reason.
